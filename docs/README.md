# Technical Documentation

This directory is intended for the technical report and supporting documentation.

Planned report contents:
1. Problem statement and platoon model
2. Nominal vehicle-following controller
3. Control Barrier Function formulation
4. Quadratic-programming safety filter
5. Simulation setup and parameter choices
6. Results and limitations

The report should be completed only after the MATLAB implementation and figures have been reviewed. Simulation evidence alone does not establish real-world safety or a formal guarantee of string stability.
