# Simulation Results

This directory is intended for figures exported from the MATLAB simulation.

Suggested outputs:
- `inter_vehicle_distances.png` — inter-vehicle distances over time
- `vehicle_speeds.png` — leader speed and relative-speed differences
- `control_inputs.png` — nominal, CBF-filtered, and requested control inputs
- `cbf_intervention.png` — magnitude of the CBF intervention
- `cbf_safety_function.png` — safety-function values over time

These figures have not been added yet. Export them from MATLAB only after running the script and checking that the results are consistent with the model assumptions. Do not present unverified plots as validated results.
